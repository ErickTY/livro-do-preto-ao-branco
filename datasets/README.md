# Datasets do livro

Esta pasta é destinada somente a datasets autorizados para distribuição como
material complementar do livro **Do Preto ao Branco**.

Para cada dataset devem ser registrados: origem, finalidade no livro, licença
ou autorização, versão, pré-processamento, seed quando sintético e limitações
de uso.

Dados experimentais reais não serão publicados sem revisão de direitos,
confidencialidade, autorização e adequação científica.
